📡 Server-Sent Events — Real-time Updates

Why SSE And Not WebSocket?
🔹 SSE Simpler for 1-Way Broadcast
🔹 No External Library Needed
🔹 Works On Normal HTTP
🔹 Auto Reconnects on Drop
💪 Supports 200 Subscribers Simultaneously
Connection Error
Auto reconnects after 5 Seconds.
Heartbeat Every 25 Seconds to Keep Connection Alive.
// SSE Endpoint app.get('/api/events/:branchId', (req, res) => { res.setHeader('Content-Type', 'text/event-stream'); res.setHeader('Cache-Control', 'no-cache'); res.flushHeaders(); const listener = (data) => { res.write(`data: ${JSON.stringify(data)}\n\n`); }; queueEvents.on(`branch:${branchId}`, listener); const hb = setInterval(() => res.write(':heartbeat\n\n'), 25000); req.on('close', () => { queueEvents.off(`branch:${branchId}`, listener); clearInterval(hb); }); });

Queue Sync Between Multiple Screens
