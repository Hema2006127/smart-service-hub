Smart Queue System

🎫 Token System
🔹 Each branch has an independent counter in table bank_queue_counters
🔹 Token: Letter B + Number With 3 Digits (B001, B002...)
🔹 Count Resets to Zero After Queue Reset
🔹 Atomic increment By ON CONFLICT DO UPDATE
🔝 Priority System
VIP = 3 — Always Served First
Elderly / Disabled = 2 — High Priority
Normal = 1 — By Arrival Time
Inquiry: ORDER BY priority DESC, created_at ASC
🎫 Ticket Statuses
waiting 🔹 serving 🔹 done
serving 🔹 escalated 🔹 done
⚡ SSE Real-time Events
new_ticket — New Ticket
now_serving — Ticket Served Now
queue_empty — Queue is Empty
escalated — Case Referred to Manager
queue_reset — Reset

📊 Server-Sent Events — Real-time Updates

Why SSE And Not WebSocket🔹
🔹 SSE Simpler and Sufficient for 1-Way Broadcast
🔹 No External Library Needed
🔹 Works On HTTP Normal
🔹 Auto Reconnects on Drop
💪 Supports 200 Subscribers Simultaneously
Connection Error
Auto reconnects after 5 Seconds.
Heartbeat Every 25 Seconds to Keep Connection Alive.
// server.js — SSE Endpoint app.get('/api/events/:branchId', (req, res) => { res.setHeader('Content-Type', 'text/event-stream'); res.setHeader('Cache-Control', 'no-cache'); res.setHeader('Connection', 'keep-alive'); res.flushHeaders(); const listener = (data) => { res.write(`data: ${JSON.stringify(data)}\n\n`); }; queueEvents.on(`branch:${branchId}`, listener); // Heartbeat Every 25 Second const hb = setInterval(() => res.write(':heartbeat\n\n'), 25000); req.on('close', () => { queueEvents.off(`branch:${branchId}`, listener); clearInterval(hb); }); }); // Send Event From Any Route function emit(req, branchId, type, payload) { const events = req.app.get('queueEvents'); events.emit(`branch:${branchId}`, { type, ...payload }); }
